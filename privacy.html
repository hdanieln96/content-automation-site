Privacy Policy

Content Automation · Last updated September 30, 2026

Content Automation is a private tool used only by its owner to manage their own YouTube channels. This page explains what it does with Google data.

What it accesses

With the owner's permission, through Google sign-in, it reads:

  • basic channel information (channel name, ID and handle), and
  • YouTube Analytics reports for the owner's own videos: views, watch time and audience retention.

It uses read-only permissions. It cannot upload, edit or delete anything on YouTube.

How the data is used

The data is used only to show the owner how their videos perform, so they can decide what to make next. It is not used for advertising, and it is not sold, shared or transferred to anyone.

Where it is stored

Sign-in tokens and analytics numbers are stored only on the owner's own computer. They are not sent to any server run by this tool.

Keeping and deleting data

Data is kept for as long as the owner uses the tool. Access can be removed at any time at myaccount.google.com/permissions. The locally stored tokens and numbers can then be deleted from the computer.

Google API Services

Content Automation's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
